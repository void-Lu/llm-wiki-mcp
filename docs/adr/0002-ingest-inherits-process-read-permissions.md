# 摄入继承服务器进程的文件读取权限

`wiki_ingest` 不增加来源目录 allowlist、MCP roots/workspace 限制或单次越界授权 token；任何服务器进程能够读取的普通文件都可以作为摄入来源。这是 ADR-0001“立即严格收紧”的明确例外：本项目接受提示词驱动的误摄入或敏感文件摄入风险，以保持本地来源选择不受额外产品策略限制。

## 后果

- P0-1 的读取授权边界建议不实施，配置模型不新增 `ingest.allowed_roots`。
- MCP roots/workspace 既不扩权也不收窄来源；实际权限边界仍由启动服务器的操作系统账户决定。
- 仍可修复同一来源被多次打开造成的 hash/copy 不一致、目标文件名兼容性和错误/返回值脱敏；这些改进不得被描述为来源授权控制。
- 文档必须明确说明该信任模型，部署者若需要隔离，应使用低权限账户、容器或操作系统文件权限，而不是依赖 MCP 工具本身。
